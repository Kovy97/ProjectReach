# Zonen-Hintergründe (Map-Bereiche)

Lege hier `<zoneId>.png` ab — wird automatisch als Hintergrund der Zonen-Karte
und als Kampf-Backdrop gebunden (via renderer/zoneBackgrounds.ts).

Zonen-IDs (aus packages/content/src/index.ts → zones):
pastures, borderlands, ashfields, blackthorn, crypt, highlands, coast, wildwood, slagpit, idolhall

Empfohlen: querformatige Bilder (z.B. 1280×720+), dunkel/atmosphärisch, da Text & Kämpfer darüber liegen.
