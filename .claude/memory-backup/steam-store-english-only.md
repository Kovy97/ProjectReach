Für den Early-Access-Launch legt der Chef die Steam-Store-Seite **vorerst nur auf Englisch** an ("derweil", 2026-07-01). Deutsche Lokalisierung kommt evtl. später.

**How to apply:** Alle Store-Texte (Kurzbeschreibung, „Über dieses Produkt", Early-Access-Tab, Grafik-Alt-Texte, Ankündigungen) direkt auf **Englisch** liefern, nicht Deutsch-first. Steam verlangt Englisch ohnehin als Standardsprache. Die Kurzbeschreibung hat ein hartes Limit von **200–300 Zeichen**. Für Copy-Auswahl bevorzugt der Chef **inline-Textoptionen** (nummeriert, mit Zeichenzahl), nicht das AskUserQuestion-Tool.

Kontext: EA-Push läuft, Steamworks-App ist angelegt (siehe [[ea-0.1-release-push]]); Store-Draft-Quelle `design/steam-store-draft.md` war veraltet (alter Name „Hearthforge Idle", entferntes „Inscription") — aktueller Name ist [[game-title-grim-reach]] (Titel-Konflikt „Grimreach: Forsaken" noch offen).
