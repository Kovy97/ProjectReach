# Vorlagen

## Asset-Aufträge

`ASSET-BRIEF.md` ist die verbindliche Standardvorlage für Asset-Arbeit:

1. Chef oder Claude füllen **Teil A – Auftraggeber-Briefing** aus oder geben Codex eine freie Anweisung, die Codex selbst dorthin überträgt.
2. Codex prüft die Quellen und füllt **Teil B – Designauflösung** aus.
3. Nach Produktion dokumentiert Codex **Teil C – Lieferung und QA**.
4. Chef oder Claude entscheiden entsprechend ihrer Projektrolle in **Teil D – Abnahme**.

Die Vorlage ist eine Präzisionshilfe und keine Zugangshürde. Ideen, Bildreferenzen und Anweisungen können jederzeit frei vom Chef oder von Claude kommen. Niemand muss einen bereits klar formulierten Auftrag noch einmal formal ausfüllen.
