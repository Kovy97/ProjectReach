# Combat Screen — fünf Layoutstudien

`index.html` enthält fünf umschaltbare, funktionale Informationsarchitekturen für den echten
Combat-Scope von Grim Reach. Jede Variante reserviert feste Bereiche für:

- Equipment und abgeleitete Kampfwerte
- sechs Combat-Skills
- adaptiven Melee-/Ranged-/Magic-Focus
- Food und Auto-Eat
- Auto-Potion und Rebuff
- Session-Ertrag
- Zonen, Dungeons, Slayer Tower, Gegnerwahl und aktiven Kampf

Die Schalter `1920` und `3440` dienen dem Layoutvergleich. Die Studie verändert weder
Produktions-React/CSS noch Engine, Save-State oder i18n. Die Beispieltexte sind reine
Mockupdaten; bei einer Freigabe werden ausschließlich vorhandene Übersetzungsschlüssel verwendet.
