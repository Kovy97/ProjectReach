# Bank Layout Studies

<!-- codex:2026-08-01T18:18:00+02:00 -->

Five BankPage-specific functional HTML concepts based on the current production feature set.

Covered in every concept:

- NPC greeting and bank introduction
- shared search, category filters, counts and sort modes
- used/max capacity and slot-package purchase
- inventory and bank collections, empty slots and full-bank states
- deposit all, single/partial/group transfers
- variant-pouch signalling and equip-from-bank action
- shift-click and pointer drag/drop guidance
- quantity-picker modal with presets

No production BankPage code is changed by these studies. Open `index.html` and switch concepts in
the upper selector row.
