# Designbrief — Main-Menü-Unterseiten

## Auftrag

Noch keine HTML-Umsetzung. Je fünf reine Design-Mockups für:

- New Game;
- Load Game;
- Character Creation.

Gesamtumfang: 15 Mockups. Dieselbe Nummer bildet jeweils eine vollständige Designfamilie über
alle drei Screens.

## Verbindliche Inhalte

### New Game

- Titel `NEW GAME`, Aktion `BACK TO MENU`;
- fünf nummerierte Speicherplätze;
- leere Slots klar als `EMPTY SAVE SLOT` erkennbar;
- eindeutige Aktion `NEW GAME` je leerem Slot;
- Layout muss auch belegte Slots und eine spätere Überschreibwarnung tragen können.

### Load Game

- Titel `LOAD GAME`, Aktion `BACK TO MENU`;
- mehrere belegte und leere Speicherplätze;
- belegte Slots zeigen Portrait, Name, Total Level, Spielzeit und Last Played;
- Aktionen `LOAD` und `DELETE`, destruktive Aktion klar sekundär/gefährlich;
- Slots müssen schnell vergleichbar sein.

### Character Creation

- `CREATE A NEW HERO`, `EVERY LEGEND BEGINS WITH A NAME`;
- `BACK TO MENU`;
- Schritt 1 `NAME` mit ausgefülltem Beispiel `EDRIC`;
- Schritt 2 `PORTRAIT` mit sichtbarer Auswahl und `SHOW ALL`;
- Schritt 3 `STARTING STYLE` mit `MELEE`, `RANGED`, `MAGIC`;
- Primäraktion `BEGIN ADVENTURE`;
- großformatige Charaktervorschau und klare Rückmeldung der Auswahl.

## Fünf Designfamilien

1. **Ashen Gate** — monumentale Torarchitektur, Slots als befestigte Nischen, Character Creation
   als Schwurkammer.
2. **War Table** — Speicherstände als Einsatzdossiers auf einem physischen Kartentisch,
   Character Creation als Rekrutierungsakte.
3. **Frontline Registry** — schnelle militärische Registratur, höchste Informationsklarheit und
   beste Skalierung.
4. **Black Chronicle** — schwere schwarze Chronik, Speicherstände als Kapitel, Charakter als neu
   eingeschriebene Legende.
5. **Ember Reliquary** — große ausgewählte Vorschau, kompakte horizontale Galerie, cineastische
   aber bedienbare Präsentation.

## Stil und Abnahme

- 16:9 Desktop, deckende UI-Screens;
- bestehendes Grim-Reach-Logo/Panorama beziehungsweise aktuelle Character-Creation als Referenz;
- Ashen Iron, dunkle Eiche, schwarzes Leder, Eisen, zurückhaltende Bronze und Glutrot;
- keine mobile, helle, neonfarbene oder generische Hochglanz-Fantasy-Optik;
- fünf klar unterscheidbare Layouts, aber eine gemeinsame Produktidentität;
- je Screen ein Kontaktbogen und ein gepaarter Gesamtbogen.
