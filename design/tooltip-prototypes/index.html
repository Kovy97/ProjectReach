Item Tooltip Redesign — Round 3 (Task #210)

Ten tooltips, ten actual design languages — not ten variations on one wooden frame. Each column below borrows its construction logic from a different reference (Diablo IV, Elden Ring, Path of Exile, Baldur's Gate 3, an illuminated grimoire, a forge blueprint, a carved stone tablet, a glass rarity-aura, a trading card, and a "best of all nine" royal synthesis). Same two example items throughout — Gorehorn Cleaver (rare, two-handed cleaver, with a Luck suffix roll and a Power skill-boost) and Charred Breastplate (magic, chest armor) — so the layouts are the only variable.

Rarity is one shared system across every design: --rc "r,g,b" per rarity, reused for name color, header bands, glows and gems (rare = green #4ec46e, magic = blue #5b8fd6 — matches the live game's --rar-rare / --rar-magic). Cinzel loads via system fallback (no CDN); degrades to Georgia/serif if not installed.
