## 3. Scope IN (Definition of Done je Punkt)
**A. New Haven — Phase 1 (Headline):**
1. Lager-Screen als **simples 2D-Karten-Interface** (Chef-Entscheid 26.07.): Sidebar-Eintrag
   „New Haven" (unübersetzt), darin ein Karten-Grid im Design-System (Holz/Leder, ButtonNew, Citadel-Tooltips).
   Je Gebäude EINE Karte: Gebäude-Bild (wechselt mit der Ausbaustufe!), Name + Stufe I/II/III,
   aktueller Effekt, nächster Effekt, Upgrade-Kosten (Gold + Materialien mit Besitz-Anzeige),
   Bauzeit, Bau-Button (EIN Bautrupp — laufender Bau zeigt Fortschrittsbalken auf seiner
   Karte, alle anderen Buttons gesperrt mit Grund). Kopfzeile: Zentralhaus-Stufe, freie
   Bauplätze, Bautrupp-Status. KEINE Hotspot-Map/Kulissen-Szene in 0.3.0 (→ 0.4-Kandidat);
   Lager-Kulissen-Assets entfallen damit für den Chef.
2. 15 Gebäude × 3 Stufen nach `design/encampment-konzept.md` + `encampment-balance.md`
   (Stücklisten/Boost-Budget aus dem Balance-Doc, Namen/Flavor aus `lore/encampment-lore.md`).
3. EIN Bautrupp, Echtzeit-Bauzeiten über deterministische Spielzeit (offline==online),
   Bau-Fortschritt im Offline-Report („Die Hände haben gearbeitet").
4. Permanente Boosts über den bestehenden Dauer-/System-Pfad (Bank-Slots, Queue-Slots,
   Offline-Cap, Skill-Tempo, Slayer, Segen, Verkauf) — Kampfwerte bleiben unberührt.
5. Offline-Veredelung Schmelzofen/Räucherhaus (Raten aus Balance-Doc).
6. SAVE_VERSION 75→76 + Migration + Vault-Fixture nach GESETZ.
7. i18n ×7 komplett.
**B. Geerbter Unterbau (fertig, wird mitveröffentlicht):** Loadouts 1/2/3, Slayer-Geister-Fix,
