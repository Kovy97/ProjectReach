Nahkampf-Effekte

Waffe
– fps
Element

Alle Nahkampf-Effekte von Grim Reach 1.4.1, abgespielt mit dem echten Spielcode. Jede Waffenart hat eine eigene Angriffsspur und einen eigenen Einschlag, je zwei Varianten und einen Krit. Trägt die Waffe einen Status (eigener Waffeneffekt oder Rune), legt sich das Element über Spur und Einschlag. Element-Kacheln wechseln bei jedem Abspielen: Variante 1, Variante 2, Auslöser (der Status greift in diesem Schlag), Krit. Klick auf eine Kachel spielt sie ab; die Spielfigur bewegt sich je Waffenklasse wie im Kampf.
